# Checking the graph's links

Each item shows one link of the graph, two entities and a label, with every passage it
was built from. Answer **accept** if the passages state that link, **reject** if they
don't. This measures how many of the graph's links are right, so judge only what the
passages say, not what you know.

- Reject a link the passages only suggest, ask about or rule out.
- Reject the right relation between the wrong entities, for example when a name was
  linked to the wrong entry.
- One passage that states the link is enough.
