Cypher

Read-only queries on the graph. Entities are (:Entity {id, type, name}), linked by relationships named after the relation labels, with evidence (how many passages) and conditions. Passages and documents: (:Document)-[:HAS_PASSAGE]->(:Passage)-[:MENTIONS]->(:Entity).

API

Programs use the same data. Get a token with ellf services url <service name> and send it as Authorization: Bearer <token>. Every query is read-only.
